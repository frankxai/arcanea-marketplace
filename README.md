# Arcanea Marketplace

AI-powered creative intelligence plugins for conscious creators.

## Plugins Available

### Creative
- **frankx-brand** - FrankX brand voice and style guide
- **frankx-content** - Content creation engine
- **arcanea-lore** - World-building lore system
- **arcanea-design** - Design system and UI components

### Personal Development
- **soulbook-core** - Consciousness transformation framework
- **soulbook-pillars** - 7 Pillars of Conscious Living
- **spartan-discipline** - Warrior philosophy and peak performance

### Music Production
- **suno-prompt-architect** - AI music with Suno
- **vibe-os** - State-change music sessions

### Writing
- **golden-age-author** - 9-author council book writing system

### Productivity
- **conscious-creator-os** - Multi-agent orchestration for creators

### Enterprise
- **oracle-intelligence** - Oracle Cloud expertise

## Installation

```bash
# Install a single plugin
/plugin install frankx-brand@arcanea

# Install multiple plugins
/plugin install soulbook-core@arcanea suno-prompt-architect@arcanea
```

## Usage

After installation, plugins activate automatically based on context or via:

```bash
/skill frankx-brand
/skill soulbook-core
```
