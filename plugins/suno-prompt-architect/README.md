# Suno Prompt Architect Plugin

Professional Suno AI prompt engineering for transformative music.

## Installation
```bash
/plugin install suno-prompt-architect@arcanea
```

## Commands
- `/suno [style] [mood]` - Generate Suno prompt

## Agents
- **Frequency Alchemist** - Music production specialist

## Prompt Structure
```
[FOUNDATION] + [MOOD] + [INSTRUMENTATION] + [PRODUCTION] + [INTENTION]
```

- Epic / Cinematic
- Lo-fi / Jazz
- Healing / Binaural
- Drum & Bass
- Deep House
