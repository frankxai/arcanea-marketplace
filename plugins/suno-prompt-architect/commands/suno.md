# /suno Command

Generate professional Suno AI prompts for music creation.

## Usage
```
/suno [style] [mood]
```

## Styles
- `ambient` - Ambient downtempo, meditation
- `epic` - Cinematic orchestral, motivation
- `lofi` - Lo-fi hip hop, creative flow
- `healing` - Frequency healing, binaural
- `dnb` - Drum & bass, energy
- `house` - Deep house, groove

## Moods
- `focus` - Deep work concentration
- `energy` - High motivation
- `calm` - Relaxation, meditation
- `creative` - Creative flow state
- `transform` - Consciousness shift

## Example
```
/suno ambient calm
# Generates: "Ambient downtempo with ethereal pads, 
# Tibetan singing bowls, soft rain textures, 
# 528Hz healing frequencies, spacious mix, 
# 60 BPM, transcendent meditation atmosphere"
```
