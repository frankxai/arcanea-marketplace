# Spartan Discipline Plugin

The Way of the Warrior-Creator.

## Installation
```bash
/plugin install spartan-discipline@arcanea
```

## Commands
- `/spartan day` - Daily schedule
- `/spartan 300` - Training protocol
- `/spartan mantras` - Warrior wisdom
- `/spartan battle` - Three battles framework

## Agents
- **Drill Sergeant** - Accountability enforcer

## Core Principles
1. Laconic Speech - Say more with less
2. Iron Routine - Unbreakable habits
3. Voluntary Hardship - Choose discomfort
4. Excellence Over Perfection - Ship the work
5. Brotherhood - Accountable community
