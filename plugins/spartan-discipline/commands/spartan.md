# /spartan Command

Channel Spartan warrior discipline.

## Usage
```
/spartan [protocol]
```

## Protocols
- `day` - The Spartan daily schedule
- `300` - The 300 training protocol
- `mantras` - Spartan wisdom phrases
- `battle` - The three battles framework
- `laconic` - Communication discipline

## Example
```
/spartan day
# Shows full Spartan daily routine
# 0500 rise, cold exposure, training blocks...
```
