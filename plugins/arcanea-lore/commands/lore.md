# /lore Command

Access Arcanea world-building elements.

## Usage
```
/lore [topic]
```

## Topics
- `glossary` - Full terminology reference
- `mythology` - Core Arcanean mythology
- `path` - The Arcanean transformation path
- `hero` - Hero's Code narrative framework
- `alchemy` - Alchemical process framework

## Example
```
/lore glossary
# Shows full Arcanea terminology with technical equivalents
```
