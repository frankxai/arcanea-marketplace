# Arcanea Lore Plugin

Mythopoetic framework bridging technology and consciousness.

## Installation
```bash
/plugin install arcanea-lore@arcanea
```

## Commands
- `/lore glossary` - Terminology reference
- `/lore mythology` - Core mythology
- `/lore path` - Transformation path

## Key Concepts
- **The Source** - Field of infinite possibility
- **Arcane Threads** - Connections between ideas
- **The Codex** - Personal knowledge repository
- **Luminal Gates** - Threshold transformation moments

- Hero's Code (for courses)
