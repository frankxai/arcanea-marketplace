# /oracle Command

Access Oracle Cloud and enterprise AI expertise.

## Usage
```
/oracle [topic]
```

## Topics
- `architecture` - Architecture patterns
- `ai` - OCI AI Services guidance
- `security` - Security best practices
- `cost` - Cost optimization strategies
- `db` - Database services (Autonomous DB)
- `k8s` - Kubernetes on OKE

## Example
```
/oracle architecture
# Shows enterprise architecture patterns for OCI
```
