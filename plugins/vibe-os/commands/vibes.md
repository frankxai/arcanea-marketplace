# /vibes Command

Start a Vibe OS consciousness-aligned music session.

## Usage
```
/vibes [session_type]
```

## Session Types
- `focus` - Deep work concentration (60-80 BPM)
- `creative` - Creative flow state (80-110 BPM)
- `energy` - Motivation & high intensity (120-160 BPM)
- `transform` - Meditation & state change (40-60 BPM)
- `morning` - Awakening ritual
- `evening` - Integration ritual

## What It Does
1. Generates session-specific Suno prompt
2. Sets target consciousness state
3. Provides session timer suggestion
4. Includes opening/closing rituals

## Example
```
/vibes focus

# Output:
# 🎧 FOCUS SESSION
# Duration: 50 minutes (Pomodoro x2)
# Target: Deep concentration, gamma state
# 
# Suno Prompt:
# "Minimal ambient electronic, soft pulsing bass,
# crystalline textures, 70 BPM, spacious mix,
# subtle 40Hz binaural undertone, focus enhancing"
```
