# Soulbook Core Plugin

The Creator's Soulbook - comprehensive system for building every dimension of your extraordinary life.

## Installation
```bash
/plugin install soulbook-core@arcanea
```

## Commands
- `/soulbook [pillar]` - Access pillar framework
- `/soulbook assess` - Take transformation assessment

## Agents
- **Soul Strategist** - Personal transformation guide
