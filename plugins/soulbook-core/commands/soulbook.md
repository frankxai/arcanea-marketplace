# /soulbook Command

Access the Creator's Soulbook transformation framework.

## Usage
```
/soulbook [pillar|book]
```

## Options
- `energy` - Pillar 1: Physical foundation
- `mind` - Pillar 2: Mental & emotional
- `soul` - Pillar 3: Values & purpose
- `craft` - Pillar 4: Skills & output
- `capital` - Pillar 5: Resources & freedom
- `circle` - Pillar 6: Relationships
- `legacy` - Pillar 7: Integration & impact
- `symphony` - Life Symphony (for artists)
- `golden` - Golden Path (for seekers)
- `assess` - Take assessment

## Example
```
/soulbook energy
# Shows Pillar 1 framework and exercises

/soulbook symphony
# Life Symphony approach for artists
```
