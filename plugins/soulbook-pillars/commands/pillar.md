# /pillar Command

Deep dive into a specific pillar of the Soulbook.

## Usage
```
/pillar [1-7]
```

## The 7 Pillars
1. **Energy** - Body, Health, Vitality
2. **Mind** - Intellect, Emotions, Focus  
3. **Soul** - Values, Purpose, Character
4. **Craft** - Mastery, Skills, Output
5. **Capital** - Money, Business, Assets
6. **Circle** - Relationships, Audience, Community
7. **Legacy** - Vision, Purpose, Impact

## Example
```
/pillar 1
# Shows Energy pillar: exercises, habits, assessment
```
