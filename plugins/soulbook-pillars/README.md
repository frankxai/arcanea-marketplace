# Soulbook Pillars Plugin

Deep dive into each of the 7 Pillars of Conscious Living.

## Installation
```bash
/plugin install soulbook-pillars@arcanea
```

## Commands
- `/pillar 1` - Energy (Body, Health, Vitality)
- `/pillar 2` - Mind (Intellect, Emotions, Focus)
- `/pillar 3` - Soul (Values, Purpose, Character)
- `/pillar 4` - Craft (Mastery, Skills, Output)
- `/pillar 5` - Capital (Money, Business, Assets)
- `/pillar 6` - Circle (Relationships, Audience, Community)
- `/pillar 7` - Legacy (Vision, Purpose, Impact)

## Each Pillar Includes
- Core concepts and frameworks
- Assessment questions
- Daily practices
- Integration exercises
- Teacher/Visionary/Coach perspectives
