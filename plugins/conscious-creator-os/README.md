# Conscious Creator OS Plugin

The operating system for generative creators.

## Installation
```bash
/plugin install conscious-creator-os@arcanea
```

## Commands
- `/create content` - Content mode
- `/create music` - Music mode
- `/create strategy` - Strategy mode
- `/create build` - Build mode
