# /design Command

Generate Arcanea design system components.

## Usage
```
/design [component]
```

## Components
- `card` - Glassmorphic card
- `button` - Cosmic button
- `hero` - Hero section with aurora
- `nav` - Navigation component
- `form` - Form with Arcanea styling
- `palette` - Full color palette

## Example
```
/design card
# Outputs ready-to-use glassmorphic card component
```
