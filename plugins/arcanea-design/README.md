# Arcanea Design Plugin

Premium UI system for conscious creators.

## Installation
```bash
/plugin install arcanea-design@arcanea
```

## Commands
- `/design card` - Glassmorphic card
- `/design button` - Cosmic button
- `/design hero` - Hero section
- `/design palette` - Color system

## Design Principles
1. Depth through transparency (glassmorphism)
2. Cosmic color language (auroras)
3. Sacred geometry accents
4. Organic flow animations

## Color Palette
- Purple: `#8B5CF6`
- Cyan: `#06B6D4`
- Gold: `#F59E0B`
- Void: `#0F0F1A`
