# FrankX Content Plugin

Content creation engine for articles, social media, and marketing materials.

## Installation
```bash
/plugin install frankx-content@arcanea
```

## Commands
- `/content linkedin [topic]` - Create LinkedIn post
- `/content newsletter [topic]` - Create newsletter
- `/content blog [topic]` - Create blog article

## Agents
- **Creation Engine** - Multi-format content generation
