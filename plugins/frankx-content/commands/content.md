# /content Command

Generate FrankX-branded content for any platform.

## Usage
```
/content [type] [topic]
```

## Types
- `linkedin` - Professional thought leadership
- `newsletter` - Email deep-dive
- `blog` - Long-form article
- `thread` - Twitter/X thread
- `launch` - Product launch sequence

## Examples
```
/content linkedin "AI music production tips"
/content newsletter "weekly creator update"
/content blog "consciousness and technology"
```

## Process
1. Loads FrankX voice and positioning
2. Applies content pillar framework
3. Uses Epiphany Bridge structure
4. Includes transformation invitation
5. Ends with clear CTA
