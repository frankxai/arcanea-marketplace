# Golden Age Author Plugin

The 9-Author Council for world-class books.

## Installation
```bash
/plugin install golden-age-author@arcanea
```

## Commands
- `/author vision` - Define transformation promise
- `/author structure` - Create outline
- `/author draft` - Write first draft
- `/author refine` - Edit and polish

## The 9 Council Members
1. Visionary - Paradigm shifts
2. Researcher - Evidence
3. Storyteller - Narrative
4. Teacher - Clarity
5. Editor - Precision
6. Marketer - Positioning
7. Reader - Audience view
8. Artist - Beauty
9. Sage - Wisdom
