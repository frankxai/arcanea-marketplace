# /author Command

Activate the 9-Author Council for book development.

## Usage
```
/author [phase|council]
```

## Phases
- `vision` - Define book's transformation promise
- `research` - Build knowledge foundation
- `structure` - Create outline and arc
- `draft` - Write first draft
- `refine` - Edit and polish
- `launch` - Prepare for publication

## Council Members
- `visionary` - Paradigm-shifting ideas
- `researcher` - Evidence and credibility
- `storyteller` - Narrative and emotion
- `teacher` - Clarity and frameworks
- `editor` - Precision and polish
- `marketer` - Positioning and hook
- `reader` - Audience perspective
- `artist` - Beauty and experience
- `sage` - Wisdom and truth

## Example
```
/author vision
# Activates Visionary and Sage council members
# for defining book transformation promise
```
