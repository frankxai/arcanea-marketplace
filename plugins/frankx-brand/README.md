# FrankX Brand Plugin

Official brand voice, visual identity, and content creation framework for FrankX.

## What's Included
- **Skills:** Complete brand guidelines (voice, colors, typography, structure)
- **Commands:** `/frankx` - Apply brand to any content type
- **Agents:** Brand Guardian - ensures compliance

## Installation
```bash
/plugin install frankx-brand@arcanea
```

## Usage
```bash
# Apply brand to article
/frankx article

# Activate brand guardian
Activate Brand Guardian to review this content
```

## Brand Pillars
1. **Creator-First** - Empower independent creators
2. **Soul + Systems** - Bridge spirituality and technology
3. **Action-Oriented** - Every piece ends with next step
4. **Studio Energy** - Warmth of late-night sessions
