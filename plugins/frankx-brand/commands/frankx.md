# /frankx Command

Apply FrankX brand standards to your content.

## Usage
```
/frankx [content_type]
```

## Content Types
- `article` - Blog article with studio energy
- `social` - Social media post (LinkedIn, Twitter)
- `product` - Product page copy
- `email` - Newsletter or email sequence
- `docs` - Technical documentation with warmth

## What It Does
1. Loads FrankX brand voice guidelines
2. Applies domain-specific color palette
3. Uses studio metaphors and music analogies
4. Ensures action-oriented endings
5. Validates against brand checklist

## Example
```
/frankx article

# Creates content with:
# - Cinematic opening hook
# - Studio-life grounding
# - Technical accuracy with warmth
# - Clear next action
```
